# ByThumbnailImage 缩略图组件

# 组件简介

ByThumbnailImage 用于在表格、列表等场景中展示图片缩略图，具备以下能力：

  • 懒加载：进入视口后再加载缩略图，减少首屏请求压力
  • 缩略图缓存：相同 URL 与尺寸复用缓存，并发请求自动排队
  • 点击预览：默认点击后通过内置弹窗（ByDialog）展示大图
  • 自定义预览：监听 @preview 事件后可接管预览逻辑

常用于水印图、商品图、凭证截图等字段的表格列展示。

# 基础用法

<template>
  <by-thumbnail-image :src="imageUrl" />
</template>

<script>
export default {
  data() {
    return {
      imageUrl: 'https://example.com/photo.jpg'
    }
  }
}
</script>

# 空状态

无 src 时显示占位文案，默认为 -，可通过 empty-text 自定义。

<template>
  <div>
    <by-thumbnail-image />
    <by-thumbnail-image empty-text="暂无图片" />
  </div>
</template>

# 尺寸

通过 size 控制缩略图展示区域的宽高（单位 px），默认 64。

<template>
  <div>
    <by-thumbnail-image :src="imageUrl" :size="48" />
    <by-thumbnail-image :src="imageUrl" :size="64" />
    <by-thumbnail-image :src="imageUrl" :size="96" />
  </div>
</template>

# 点击预览

默认开启预览（previewable 默认为 true），点击缩略图会打开内置预览弹窗。

可通过 preview-title、preview-width 配置弹窗标题与宽度。

<template>
  <by-thumbnail-image
    :src="imageUrl"
    preview-title="商品图片"
    preview-width="600px"
  />
</template>

# 缩略图与原图分离

列表中展示较小缩略图地址，预览时查看高清原图，可分别传入 src 与 preview-src：

<template>
  <by-thumbnail-image
    :src="thumbUrl"
    :preview-src="originalUrl"
    preview-title="原图预览"
  />
</template>

# 禁用预览

<template>
  <by-thumbnail-image :src="imageUrl" :previewable="false" />
</template>

# 自定义预览

监听 preview 事件后，组件不再调用内置预览弹窗，由业务自行处理（例如接入图片查看器、新窗口打开等）。

<template>
  <by-thumbnail-image :src="imageUrl" @preview="handlePreview" />
</template>

<script>
export default {
  methods: {
    handlePreview({ src, title, width }) {
      // src: 预览图片地址（preview-src 优先，否则为 src）
      // title: 预览标题
      // width: 建议弹窗宽度
      window.open(src)
    }
  }
}
</script>

# 表格场景

在 el-table、ByTable 等表格列中直接使用即可：

<template>
  <el-table :data="tableData" border size="small">
    <el-table-column label="名称" prop="name" width="120" />
    <el-table-column label="水印图" width="100" align="center">
      <template slot-scope="{ row }">
        <by-thumbnail-image :src="row.watermark_url" :size="64" />
      </template>
    </el-table-column>
  </el-table>
</template>

<script>
export default {
  data() {
    return {
      tableData: [
        { name: '商品 A', watermark_url: 'https://example.com/a.jpg' },
        { name: '商品 B', watermark_url: '' }
      ]
    }
  }
}
</script>

# 懒加载控制

默认 load-enabled 为 true，组件会在空闲时延迟激活加载，并在进入视口后请求缩略图。

在虚拟滚动、折叠面板等场景下，若希望暂时禁止加载，可设为 false：

<template>
  <by-thumbnail-image :src="imageUrl" :load-enabled="expanded" />
</template>

# 属性

参数 说明 类型 默认值
src 图片地址；为空时显示空状态文案 String ''
preview-src 预览大图地址；未设置时使用 src String ''
size 缩略图展示尺寸（px） Number 64
preview-title 预览弹窗标题 String 图片预览
preview-width 预览弹窗宽度 String 500px
previewable 是否允许点击预览 Boolean true
empty-text 无 src 时的占位文案 String -
load-enabled 是否启用懒加载 Boolean true

# 事件

事件名 说明 回调参数
preview 点击缩略图且 previewable 为 true 时触发；监听此事件后不会打开内置预览弹窗 { src, title, width }

# 样式

组件样式位于 src/style/by-thumbnail-image.scss，已随主样式入口 src/style/index.scss 统一导出，使用库时引入主样式即可，无需单独引入。

# 使用注意

  1. 请通过 Vue.use(ByComponents) 注册组件库，以确保预览弹窗使用与业务应用相同的 Vue 实例与插件上下文。
  2. 引入组件库样式：import '@weitutech/by-components/lib/index.css'（或项目内等效路径）。
  3. 仅使用 <by-thumbnail-image /> 且未监听 @preview 时，点击会自动打开内置预览；若监听了 @preview，需自行实现预览逻辑。
  4. 图片地址需支持跨域访问（CORS），否则缩略图生成可能回退为 Image 加载方式，部分场景下会失败。
