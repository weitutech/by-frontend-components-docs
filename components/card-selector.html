# 卡片选择器组件（ByCardSelector）

# 组件简介

ByCardSelector 是一个卡片式的单选 / 多选组件，行为类似 Element UI 的 el-radio-group / el-checkbox-group，但每个选项以"卡片"形式展示，可包含图标、标题、描述、标签（多个 Tag）、单项 tooltip 等富信息。组件特性：

  • 统一字段约定 + 自动回退：默认按 value / label 取数；业务直接传 id / name 形态时无需任何配置即可工作（自动回退）
  • 横向 / 纵向 两种排列方向，纵向自动换列
  • 卡片宽度统一控制（card-width，可选 100–600px 范围内的任意值）
  • 三档尺寸（large / default / small）影响内边距、图标与字号
  • 整组禁用 与 单项禁用（支持布尔字段或业务约定的数值字段，如 status === 1 可选）
  • 整组说明 tooltip（tooltips）：在最后一个选项后追加问号悬停提示
  • 完全自定义渲染：通过 #card 插槽接管整张卡片内容，或仅通过 #icon 自定义图标区

# 基础用法

<template>
  <by-card-selector v-model="value" :options="options" />
</template>

<script>
export default {
  data() {
    return {
      value: 'a',
      options: [
        { value: 'a', label: '方案 A', description: '适合标准业务场景', icon: 'el-icon-s-opportunity' },
        { value: 'b', label: '方案 B', description: '增强型配置' },
        { value: 'c', label: '方案 C', description: '企业定制', disabled: true }
      ]
    }
  }
}
</script>

# 单选 / 多选

通过 multiple 切换；单选时 v-model 为单值，多选时为数组。

<template>
  <!-- 单选 -->
  <by-card-selector v-model="singleValue" :options="options" />

  <!-- 多选 -->
  <by-card-selector v-model="multiValues" :options="options" multiple />
</template>

<script>
export default {
  data() {
    return {
      singleValue: 'a',
      multiValues: ['a', 'c']
    }
  }
}
</script>

# 字段约定与自动回退（label/value 与 id/name 通用）

组件默认按 label / value 字段读取选项数据，但同时内置了 id / name 形态的自动回退——在业务方未显式配置 option-props 的前提下，数据项中若不存在 label / value 字段，会自动改读 name / id。这一规则覆盖三种典型场景：

<template>
  <!-- 1) value/label 形态（既有约定，原样工作） -->
  <by-card-selector v-model="v1" :options="[{ value: 1, label: 'A' }, { value: 2, label: 'B' }]" />

  <!-- 2) id/name 形态（自动回退，零配置） -->
  <by-card-selector v-model="v2" :options="[{ id: 1, name: 'A' }, { id: 2, name: 'B' }]" />

  <!-- 3) 完全自定义字段（显式配置即关闭回退） -->
  <by-card-selector
    v-model="v3"
    :options="[{ code: 1, title: 'A' }]"
    :option-props="{ label: 'title', value: 'code' }"
  />
</template>

回退触发条件：组件仅在数据项上 hasOwnProperty(key) === false（字段根本不存在）时回退；业务方有意 label: '' / label: null 不会被覆盖。一旦在 option-props 中显式写出 label / value（即便值与默认相同），对应字段的自动回退就会关闭，便于严格控制取值来源。

# 选项数据完整字段

每个选项可包含以下字段（字段名可通过 option-props 自定义）：

{
  value: 'a',                   // 选项值（v-model 命中）
  label: '方案 A',              // 卡片标题
  description: '适合标准场景',  // 卡片描述（可选）
  icon: 'el-icon-s-opportunity',// 图标：el-icon-* 类名 / 图片 URL / data:image
  tooltip: '包含基础能力',      // 标题旁问号悬停说明（可选）
  tags: ['推荐', '标准版'],     // 卡片标签数组，超出部分以 +N 折叠（可选）
  disabled: false               // 是否禁用（也可通过 disabled-field 改用其它字段）
}

icon 字段同时支持：

  • Element UI 图标类名（如 el-icon-s-opportunity）
  • http(s)://... 图片地址
  • data:image/... Data URL
  • .png / .jpe?g / .gif / .webp / .svg 文件后缀（含查询串）

未提供 icon 时，组件会用 label 首字母作为占位（中文亦支持，取首字符）。

# 横向 / 纵向排列

direction 默认 horizontal，自动换行。纵向场景建议同时设置 vertical-max-height，便于 flex 换列产生整齐的分栏效果。

<template>
  <by-card-selector
    v-model="value"
    :options="options"
    direction="vertical"
    vertical-max-height="280px"
  />
</template>

# 统一卡片宽度（card-width）

card-width 为组件级统一卡片宽度（像素），用于在不同业务页面快速控制视觉密度。

  • 合法范围 100–600，超出会自动夹紧到边界
  • 支持数字或字符串（如 240、"320px"）
  • 未设置时由 size 与内置样式决定列宽
<template>
  <by-card-selector v-model="value" :options="options" :card-width="280" />
</template>

# 尺寸（size）

size 控制内边距、图标与字号比例，可选 large / default / small：

<template>
  <by-card-selector v-model="value" :options="options" size="small" />
</template>

# 禁用：整组禁用 / 单项禁用 / 自定义字段

  • disabled 控制整组禁用
  • 单项禁用默认读 disabled 字段（布尔 true 表示禁用）
  • 可通过 disabled-field 切换为业务约定字段，数值类型时 1 表示可选，非 1 表示不可选（典型如 status）
<template>
  <by-card-selector
    v-model="value"
    :options="options"
    disabled-field="status"
  />
</template>

<script>
export default {
  data() {
    return {
      value: 'ok',
      options: [
        { value: 'ok', label: '可用套餐', status: 1 },
        { value: 'soldout', label: '已售罄', status: 0 },   // 禁用
        { value: 'maint', label: '维护中', status: 2 }      // 禁用
      ]
    }
  }
}
</script>

# 右侧打钩选中指示（show-checkmark）

show-checkmark 控制选中态是否在右侧附加一个圆形打钩指示，默认 true。 若整体风格不需要该指示（如自定义了 #card 插槽），可显式设为 false，仅保留边框 + 底色的选中视觉。

<template>
  <by-card-selector v-model="value" :options="options" :show-checkmark="false" />
</template>

# 组件级说明 tooltips

tooltips 用于在所有选项之后追加一个问号，悬停展示整组级别的说明文案；它与单选项内的 tooltip 字段互相独立。

<template>
  <by-card-selector
    v-model="value"
    :options="options"
    tooltips="用于解释整组「营销场景」的含义；仅在有 tooltips 文案时显示本问号。"
  />
</template>

# 自定义字段映射（option-props）

业务字段与默认不一致时，通过 option-props 显式映射；可仅覆盖需要变动的字段，未覆盖的字段沿用默认。

<template>
  <by-card-selector
    v-model="value"
    :options="optionsMapped"
    :option-props="{ value: 'id', label: 'name', description: 'desc', tags: 'tags' }"
  />
</template>

<script>
export default {
  data() {
    return {
      value: 101,
      optionsMapped: [
        { id: 101, name: '华东节点', desc: '延迟较低', tags: ['热门'] },
        { id: 102, name: '华北节点', desc: '合规友好', tags: ['企业'] },
        { id: 103, name: '华南节点', desc: '备用', tags: [] }
      ]
    }
  }
}
</script>

仅当业务字段不是 label/value 或 id/name 这两种常见约定时，才需要显式配置 option-props。

# 完全自定义卡片渲染（#card 插槽）

#card 插槽接管整张卡片的内部结构；插槽参数为 { item, index, selected, disabled }，使用方需自行处理选中态样式（推荐复用 is-selected 类名）。

<template>
  <by-card-selector v-model="value" :options="options">
    <template #card="{ item, selected, disabled }">
      <div class="custom-card" :class="{ 'is-selected': selected, 'is-disabled': disabled }">
        <span class="custom-card__title">{{ item.label }}</span>
        <el-tag v-if="selected" type="success" size="mini">已选</el-tag>
      </div>
    </template>
  </by-card-selector>
</template>

# 自定义图标渲染（#icon 插槽）

仅希望接管图标区时，使用 #icon 插槽；其余卡片结构沿用组件默认。

<template>
  <by-card-selector v-model="value" :options="options">
    <template #icon="{ item }">
      <my-svg-icon :name="item.iconName" />
    </template>
  </by-card-selector>
</template>

# 键盘交互

组件默认支持键盘导航，便于在表单中通过 Tab 链路操作：

  • Tab：聚焦当前组件中第一个可用选项
  • ← / ↑：向前移动焦点（仅在可用选项之间循环）
  • → / ↓：向后移动焦点
  • Space / Enter：切换当前聚焦项的选中态

禁用项会自动跳过；整组禁用时键盘交互失效。

# 属性

参数 说明 类型 默认值
value / v-model 绑定值；单选为选项 value，多选为 value 数组 String / Number / Boolean / Object / Array null
options 选项数据数组 Array []
multiple 是否多选 Boolean false
direction 排列方向；可选 horizontal / vertical String 'horizontal'
vertical-max-height 纵向排列时容器最大高度，便于 flex 换列；仅 direction='vertical' 时生效 String '320px'
size 尺寸：large / default / small，控制内边距、图标与字号 String 'default'
card-width 统一卡片宽度（像素）；合法范围 100–600，超出自动夹紧；未设置时由 size 与样式决定 Number / String null
disabled 整组禁用 Boolean false
option-props 选项字段映射；默认 { value, label, description, icon, tooltip, tags }。未显式配置 label 时启用 label → name 回退，未显式配置 value 时启用 value → id 回退 Object {}
disabled-field 单项禁用字段名；数值 1 表示可选，非 1 不可选；布尔 true 表示禁用 String 'disabled'
option-key-field 选项唯一键字段，用于 :key；不传时复用 value 字段（含 id 自动回退） String ''
max-visible-tags 单项标签最多展示个数，其余以 +N 省略 Number 3
tooltips 组件级说明文案；有内容时在所有选项之后展示问号，悬停查看 String / Number ''
show-checkmark 是否在卡片右侧展示圆形打钩选中指示 Boolean true

# 事件

事件名称 说明 回调参数
input v-model 同步事件；选中变化时触发 当前选中值
change 选中变化时触发；单选时为单值，多选时为数组（与 input 同时触发，方便监听） 当前选中值

# 插槽

名称 作用域参数 说明
card { item, index, selected, disabled } 完全自定义整张卡片内部结构；启用后组件默认卡片结构不再渲染，使用方需自行处理选中态视觉
icon { item, index } 仅自定义图标区；其余卡片结构沿用组件默认

# 使用建议

  • 当业务数据已经是 id/name 形态时，直接传 options，无需配置 option-props ——组件会自动回退取值
  • 多选场景下建议显式设置 card-width，避免不同选项数据下卡片宽度跳动
  • 自定义 #card 插槽时，记得在样式里同时处理 .is-selected / .is-disabled 两种状态，与组件内置的可访问性属性（aria-selected / aria-disabled）保持一致
  • 单项级说明用选项的 tooltip 字段；整组级说明用组件级 tooltips 属性，不要混用
