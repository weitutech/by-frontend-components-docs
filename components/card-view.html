# 卡片区块组件（ByCardView）

# 组件简介

ByCardView 是一个轻量的卡片容器组件：带可选的标题行（标题文案 + 右侧附加区域），下方为可自由编排的正文内容。 组件样式采用 .by-card-view* 命名空间，与宿主项目里常见的 .section-title 等类名互不冲突，可在任何业务页面里安全使用，常用于：

  • 表单分组：将一段表单包裹在卡片中，统一展示分组标题与说明
  • 信息看板：在列表/详情页中用来呈现一块独立的数据区块
  • 与 栅格布局组件 配合，作为单个栅格卡片的内容容器

# 基础用法

<template>
  <by-card-view title="基础信息">
    <p>这是卡片正文，可以放任意内容，例如表单、列表、图表等。</p>
  </by-card-view>
</template>

# 标题右侧附加区域（#extra）

通过具名插槽 extra 在标题右侧追加按钮、开关等控件，常用于卡片级的开关或操作入口。

<template>
  <by-card-view title="分配规则配置">
    <template #extra>
      <el-switch v-model="ruleEnabled" />
    </template>

    <p>开关打开后，下面的规则配置生效。</p>
  </by-card-view>
</template>

<script>
export default {
  data() {
    return {
      ruleEnabled: false
    }
  }
}
</script>

# 自定义标题节点（#title）

title / heading 只支持纯文本；当标题需要混合图标、徽标等富文本结构时，使用具名插槽 title。 父级即便只写了 <template #title> 占位也会被识别，组件会自动跳过默认 title 文案的渲染。

<template>
  <by-card-view>
    <template #title>
      <i class="el-icon-warning" style="color: #f56c6c; margin-right: 4px"></i>
      <span>风险提示</span>
      <el-tag size="mini" type="danger" style="margin-left: 6px">高危</el-tag>
    </template>

    <p>当账号检测到异常登录时，会展示在此卡片中。</p>
  </by-card-view>
</template>

# 整块替换标题行（custom-header）

当默认"左标题 + 右附加"两段式结构满足不了需要时，可设置 custom-header，整块标题行由 #header 插槽接管。 启用该模式后，title / heading / #title / #extra 均不会渲染。

<template>
  <by-card-view custom-header>
    <template #header>
      <div class="my-card-header">
        <el-breadcrumb>
          <el-breadcrumb-item>项目</el-breadcrumb-item>
          <el-breadcrumb-item>详情</el-breadcrumb-item>
        </el-breadcrumb>
        <el-button size="mini">刷新</el-button>
      </div>
    </template>

    <p>完全自定义标题行的卡片正文。</p>
  </by-card-view>
</template>

# 无边框模式（plain）

适用于已经处于带边框容器（如外层 dialog、栅格卡片）内部、又希望保留标题/正文结构的场景。 设置 :plain="true" 会去掉卡片外边框与默认 padding，仅保留内部排版。

<template>
  <by-card-view title="任务进度" :plain="true">
    <el-progress :percentage="60" />
  </by-card-view>
</template>

# 标题省略时的行为

  • 当 title / heading 均为空，且未提供 #title、#extra 插槽时，组件不会渲染标题行，仅保留正文区域，可作为一个纯粹的"内容盒子"使用
  • 当存在 #extra 但没有任何标题文案时，标题行仍然渲染（仅展示右侧附加区域），用于在卡片右上角放置独立的操作按钮
<template>
  <!-- 仅作为内容盒子，不渲染标题行 -->
  <by-card-view>
    <p>纯正文内容。</p>
  </by-card-view>

  <!-- 仅渲染右上角操作，无标题文案 -->
  <by-card-view>
    <template #extra>
      <el-button size="mini" icon="el-icon-refresh">刷新</el-button>
    </template>
    <p>正文内容。</p>
  </by-card-view>
</template>

# 属性

参数 说明 类型 默认值
title 标题文案 String ''
heading 等同 title；当宿主框架/编辑器吞掉 title 属性时（如部分模板）可改用 heading String ''
plain 无边框模式，去掉卡片外边框 Boolean false
custom-header 为 true 时启用 #header 插槽整块替换默认标题行，title / #title / #extra 失效 Boolean false

title 与 heading 同时存在时，heading 优先（用于宿主项目里 title 易被吞掉的兜底场景）。

# 插槽

名称 说明
default 卡片正文内容
title 自定义标题节点；非空时优先于 title / heading 字符串。父级即便写了空的 <template #title> 占位，也会跳过默认文案的渲染
extra 标题行右侧附加区域，常用于开关、按钮、说明文字
header 仅在 custom-header="true" 时生效，整块替换标题行

# 事件

组件不主动派发事件；事件通过插槽内部的子组件自行处理。

# 使用建议

  • 在表单页里多块结构相似的卡片，可统一用 ByCardView title="…" 包裹，避免每处都手写一遍"灰底标题条 + 内容容器"样板
  • 与 栅格布局组件 ByGridLayout 搭配时，每个栅格卡片的内容建议外层套一层 ByCardView，再通过 :plain="true" 去除多余边框，由 grid-item 提供最外层边框
  • 当某个区块的"标题旁边"经常变化（如带筛选条件、Tabs）时，使用 custom-header 而不是嵌套多层 extra，能让结构更清晰
