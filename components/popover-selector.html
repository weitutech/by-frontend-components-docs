# ByPopoverSelector 弹出层选择器

弹出层选择器组件，基于 Element UI 的 el-popover 实现，支持单选和多选模式。

# 功能特性

  • ✅ 支持单选和多选模式
  • ✅ 可配置最大显示行数，超出行数自动多列展示
  • ✅ 支持自定义按钮文本、类型、尺寸
  • ✅ 支持自定义弹出层位置和宽度
  • ✅ 支持禁用和加载状态
  • ✅ 支持自定义选项键名配置
  • ✅ 完整的选中值回显功能
  • ✅ 响应式设计，支持移动端
  • ✅ 丰富的交互效果和动画

# 基础用法

# 单选模式

<template>
  <by-popover-selector
    v-model="selectedValue"
    :options="options"
    title="选择城市"
    button-text="选择城市"
    @change="handleChange"
  />
</template>

<script>
export default {
  data() {
    return {
      selectedValue: null,
      options: [
        { id: 'beijing', name: '北京' },
        { id: 'shanghai', name: '上海' },
        { id: 'guangzhou', name: '广州' },
        { id: 'shenzhen', name: '深圳' }
      ]
    }
  },
  methods: {
    handleChange(value, option) {
      console.log('选中值:', value)
      console.log('选中选项:', option)
    }
  }
}
</script>

# 多选模式

<template>
  <by-popover-selector
    v-model="selectedValues"
    :options="options"
    title="选择技能"
    button-text="选择技能"
    :multiple="true"
    @change="handleChange"
  />
</template>

<script>
export default {
  data() {
    return {
      selectedValues: [],
      options: [
        { id: 'vue', name: 'Vue.js' },
        { id: 'react', name: 'React' },
        { id: 'angular', name: 'Angular' },
        { id: 'nodejs', name: 'Node.js' }
      ]
    }
  },
  methods: {
    handleChange(values, options) {
      console.log('选中值:', values)
      console.log('选中选项:', options)
    }
  }
}
</script>

# API

# Props

参数 说明 类型 可选值 默认值
options 选项数据源 Array — []
value 当前选中的值（单选） String/Number — null
values 当前选中的值（多选） Array — []
multiple 是否多选 Boolean — false
title 弹出层标题 String — ''
buttonText 按钮文本 String — '选择'
buttonType 按钮类型 String primary/success/warning/danger/info/text default
buttonSize 按钮尺寸 String medium/small/mini small
tiny 是否使用超小按钮 Boolean — false
placement 弹出层位置 String top/top-start/top-end/bottom/bottom-start/bottom-end/left/left-start/left-end/right/right-start/right-end bottom-start
popoverWidth 弹出层宽度 String/Number — 300
disabled 是否禁用 Boolean — false
loading 是否加载中 Boolean — false
confirmText 确认按钮文本 String — '确定'
cancelText 取消按钮文本 String — '取消'
optionProps 选项的键名配置 Object — { label: 'name', value: 'id', disabled: 'disabled' }

# Events

事件名 说明 回调参数
change 选择发生变化时触发 (value/values, option/options)
confirm 点击确认按钮时触发 (value/values)
cancel 点击取消按钮时触发 —
show 弹出层显示时触发 —
hide 弹出层隐藏时触发 —

# Methods

方法名 说明 参数
clear 清空选择 —
setSelection 设置选择 (value)

# 高级用法

# 自定义选项键名

<template>
  <by-popover-selector
    v-model="selectedValue"
    :options="customOptions"
    :option-props="{ label: 'title', value: 'code' }"
    title="选择部门"
  />
</template>

<script>
export default {
  data() {
    return {
      selectedValue: null,
      customOptions: [
        { code: 'tech', title: '技术部' },
        { code: 'product', title: '产品部' },
        { code: 'design', title: '设计部' }
      ]
    }
  }
}
</script>

# 禁用状态和加载状态

<template>
  <div>
    <!-- 禁用状态 -->
    <by-popover-selector v-model="value1" :options="options" :disabled="true" button-text="禁用状态" />

    <!-- 加载状态 -->
    <by-popover-selector v-model="value2" :options="options" :loading="true" button-text="加载中" />
  </div>
</template>

# 大量数据展示

<template>
  <by-popover-selector v-model="selectedValue" :options="largeOptions" title="选择项目" :popover-width="400" />
</template>

<script>
export default {
  data() {
    return {
      selectedValue: null,
      largeOptions: [] // 大量数据会显示在弹出层中
    }
  }
}
</script>

# 超小按钮

<template>
  <div>
    <!-- 超小单选按钮 -->
    <by-popover-selector v-model="selectedValue" :options="options" title="选择城市" button-text="选择" :tiny="true" />

    <!-- 超小多选按钮 -->
    <by-popover-selector
      v-model="selectedValues"
      :options="options"
      title="选择技能"
      button-text="技能"
      :multiple="true"
      :tiny="true"
    />
  </div>
</template>

<script>
export default {
  data() {
    return {
      selectedValue: null,
      selectedValues: [],
      options: [
        { id: 'beijing', name: '北京' },
        { id: 'shanghai', name: '上海' }
      ]
    }
  }
}
</script>

# 样式定制

组件使用 CSS 变量，可以通过覆盖变量来自定义样式：

.by-popover-selector {
  --bycomp-primary-color: #409eff;
  --bycomp-text-color-normal: #606266;
  --bycomp-hover-bg-enabled: #f5f7fa;
  --bycomp-hover-color-enabled: #409eff;
}

# 注意事项

  1. 按钮文本由外部控制，不会自动显示选中项名称
  2. 选项数据支持字符串数组或对象数组格式
  3. 组件会自动处理选项的禁用状态
  4. 大量数据会在弹出层中显示，支持滚动查看
  5. 支持id为0、undefined等特殊值的选项
