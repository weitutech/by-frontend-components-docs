# ByTag 标签组件

基于 Element UI el-tag 二次封装，继承其全部属性、事件与插槽。主要增强：扩展更多 type 类型，并为每种扩展类型提供统一的背景、边框、文字一套配色，便于在业务中做更多语义区分。

# 基础用法

<template>
  <div>
    <by-tag>默认标签</by-tag>
    <by-tag type="primary">主要</by-tag>
    <by-tag type="success">成功</by-tag>
    <by-tag type="danger">危险</by-tag>
  </div>
</template>

# 原生 type

与 el-tag 一致，支持：success、info、warning、danger。

<template>
  <div>
    <by-tag type="success">success</by-tag>
    <by-tag type="info">info</by-tag>
    <by-tag type="warning">warning</by-tag>
    <by-tag type="danger">danger</by-tag>
  </div>
</template>

# 扩展 type

在原生四种类型之外，支持以下扩展类型。色系之间区分明显、颜色区分度大：

蓝系 primary / blue / navy / sky 主色蓝 / 天蓝 / 藏青 / 亮天蓝
灰系 default / slate / charcoal 中性灰 / 深灰 / 炭灰
墨蓝系 ink 墨蓝（深蓝黑）
紫系 purple / violet / lavender 紫 / 深紫 / 薰衣草
靛蓝系 indigo 蓝紫过渡
青蓝系 cyan / teal / aqua 青 / 青绿 / 水绿
绿系 mint / lime / forest / olive / sage 薄荷绿 / 黄绿 / 森林绿 / 橄榄绿 / 鼠尾草绿
红系 crimson / rose / scarlet 深红 / 玫红 / 朱红
粉系 pink / blossom / magenta 粉 / 樱粉 / 品红
橙系 orange / coral / brick 橙 / 珊瑚 / 砖红
黄棕系 amber / gold / lemon / brown 琥珀 / 金 / 柠檬黄 / 棕

    <by-tag type="indigo">indigo</by-tag>
  </div>

# 尺寸与可关闭

size、closable 等与 el-tag 用法一致。

<template>
  <div>
    <by-tag type="primary" size="medium">medium</by-tag>
    <by-tag type="primary" size="small">small</by-tag>
    <by-tag type="primary" size="mini">mini</by-tag>
    <by-tag type="primary" closable @close="handleClose">可关闭</by-tag>
  </div>
</template>

<script>
export default {
  methods: {
    handleClose() {
      this.$message.info('标签已关闭')
    }
  }
}
</script>

# 主题效果 effect

支持 effect="dark"、effect="plain" 等，与 el-tag 一致。扩展 type 配合不同 effect 时，边框与文字颜色由组件样式统一控制。

<template>
  <div>
    <by-tag type="primary" effect="dark">primary dark</by-tag>
    <by-tag type="primary" effect="plain">primary plain</by-tag>
  </div>
</template>

# 属性

除下表所列的扩展属性外，其余属性与 Element UI Tag (opens new window) 完全一致（如 size、closable、effect、hit、round、disable-transitions、color 等）。

参数 说明 类型 可选值 默认值
type 类型。原生：success / info / warning / danger；扩展共 37 种，见上文色系表（区分度大） String 见上文 —
  • 当 type 为扩展类型时，组件通过内部样式表提供整套配色，此时传入的 color 会被忽略。
  • 未在组件中声明的属性会通过 $attrs 透传到内部 el-tag，因此所有 el-tag 支持的属性均可直接使用。

# 事件

与 el-tag 一致，透传所有事件（如 close、click 等）。

事件名 说明
close 关闭标签时触发（需设置 closable）
click 点击标签时触发

# 插槽

插槽名 说明
default 标签内容

# 样式

组件扩展类型的样式位于 src/style/by-tag.scss，已随主样式入口 src/style/index.scss 统一导出，使用库时引入主样式即可，无需单独引入 by-tag 样式。
