# ByCommonInput 通用输入框

基于 Element UI el-input 封装，保留所有原生属性与事件，并新增批量输入能力（批量内容会按英文逗号回填）。

# 基础用法

<template>
  <by-common-input v-model="text" placeholder="请输入内容" clearable size="mini" />
</template>

<script>
export default {
  data() {
    return {
      text: ''
    }
  }
}
</script>

# 批量输入

<template>
  <by-common-input
    v-model="tags"
    show-batch-input
    placeholder="请输入，或点击批量输入"
    :batch-input-popover-title="'批量输入'"
    :batch-input-placeholder="'多个请用换行、逗号、分号、空格分隔'"
    :batch-input-popover-width="320"
    clearable
    size="mini"
    @batch-input="handleBatchInput"
  />
</template>

<script>
export default {
  data() {
    return {
      tags: ''
    }
  },
  methods: {
    handleBatchInput(raw, processed) {
      // raw 为原始内容，processed 为转为英文逗号后的内容
      console.log(raw, processed)
    }
  }
}
</script>

# 属性

除以下扩展属性外，其余属性、事件与 el-input 完全一致：

属性 说明 类型 默认值
showBatchInput 是否显示批量输入按钮 Boolean false
batchInputPopoverTitle 批量输入弹窗标题 String 批量输入
batchInputPlaceholder 批量输入框 placeholder String 多个请用换行、逗号、分号、空格分隔
batchInputPopoverWidth 批量输入弹窗宽度 String / Number 300

# 事件

事件名 说明 回调参数
batch-input 批量输入确认时触发 (rawContent, processedContent) 原始内容与英文逗号分隔后的内容

# 样式

组件样式位于 src/style/common-input.scss，已随主样式入口 src/style/index.scss 统一导出，无需单独引入。
