# ByCascaderPanelPro 级联面板选择器（Pro 版）

ByCascaderPanelPro 是 ByCascaderPanel 的 高性能版本，面向 大数据量级联 场景（如数万～十万级节点）。对外用法与原版保持一致，可作为 drop-in 替换使用。

# 为什么需要 Pro 版

原版基于 Element UI 的 el-cascader-panel，在节点量较大时容易出现：

  • 初始化慢（全量 DOM + 深拷贝数据）
  • 列滚动、勾选、全选卡顿
  • 大量选中后右侧已选列表渲染困难

Pro 版在内部替换为自研虚拟级联面板，通过 扁平化存储、列内虚拟滚动、紧凑选中模式 等方式解决上述问题，不改变业务侧的接入方式。

# 适用场景

场景 建议
节点量较小（如 < 1000） 原版 / Pro 均可
节点量大、层级深、全选多 推荐 Pro
行政区域、组织树等超大树 推荐 Pro

# 基础用法

与原版相同，仅组件名不同：

<template>
  <ByCascaderPanelPro v-model="selectedValues" :options="options" :panel-height="300" @change="handleChange" />
</template>

<script>
export default {
  data() {
    return {
      selectedValues: ['lisi', 'zhaoliu'],
      options: [
        /* 与 ByCascaderPanel 相同的数据结构 */
      ]
    }
  },
  methods: {
    handleChange(data) {
      // data: { values, valuesPath, items, count }
      console.log('选择变化:', data)
    }
  }
}
</script>

# 引入方式

import { ByCascaderPanelPro } from '@weitutech/by-components'

Vue.use(ByCascaderPanelPro)
// 或局部注册

# 聚合模式

<ByCascaderPanelPro
  v-model="selectedValues"
  :options="options"
  :cascader-props="{ multiple: true }"
  :aggregation-mode="true"
  :panel-height="300"
  @change="handleChange"
/>

# 方法调用

与原版一致，通过 ref 调用：

<ByCascaderPanelPro ref="panel" v-model="selectedValues" :options="options" />

<!-- this.$refs.panel.clearSelection() -->
<!-- this.$refs.panel.setValue([...]) -->
<!-- this.$refs.panel.getSelectedData() -->

# Pro 版新增配置（可选）

以下 Props 为 Pro 版独有，不传则使用默认值，不影响从原版迁移：

参数 说明 默认值
columnMinWidth 级联列最小宽度（px） 180
columnMaxWidth 级联列最大宽度（px），超出显示省略号 420

# 与原版的关系

  • Props、Events、Methods、v-model 数据格式：与 ByCascaderPanel 一致
  • 单选 / 多选、搜索、批量搜索、全选、聚合模式、查看模式、禁用等：行为对齐原版
  • 详细字段说明、事件参数、方法返回值、聚合模式约定、注意事项：请参阅 ByCascaderPanel 文档

# 从原版迁移

  1. 将模板中的 ByCascaderPanel 改为 ByCascaderPanelPro
  2. 更新 import / 组件注册名称
  3. 其余 props、v-model、@change 等 无需修改
  4. 若宿主工程覆盖了 .cascader-panel 样式，需改为 .cascader-panel-pro
