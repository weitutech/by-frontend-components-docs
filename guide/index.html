# 介绍

By Components 是一个基于 Vue2 和 Element UI 的业务组件库，提供了常用的管理后台组件，帮助开发者快速构建业务页面。

# 特性

  • 🌟 简洁易用：API 设计简洁，开箱即用
  • 🎨 美观大方：基于 Element UI 设计规范
  • 🔧 高度可配置：支持丰富的配置选项
  • 📦 按需引入：支持按需引入，减小包体积
  • 🔌 Vue2 生态：完美兼容 Vue2 项目

# 组件列表

  • ByTable - 增强表格组件
  • ByForm - 动态表单组件
  • ByPager - 分页组件
  • ByPageSearch - 页面搜索组件
  • ByFoldSearch - 折叠搜索组件
  • BySelect - 增强选择器
  • ByDatePickerRange - 日期范围选择器
